# 자재비 증액 요청, 공표 지표와 원가 구조로 검증하기

롯데건설 외주구매 PT(파트너사 자재비 증액 요청의 적정성 검증)를 준비하며 직접 수행한 분석과 검증 도구입니다.
과제 설정부터 데이터 수집, 전처리, 분석, 시각화, 인사이트 도출까지 모두 이 폴더의 코드로 재현할 수 있습니다.

## 1. 문제 정의

파트너사가 "자재값이 X% 올랐다"며 증액을 요청할 때, 그 X%는 공표 지표와 원가 구조로 설명되는가?

- Q1. 2026년 중동발 유가 충격은 자재별로 얼마나, 언제 전이됐나?
- Q2. 원료값이 내릴 때도 자재값은 같은 속도로 내려오나?
- Q3. 그렇다면 어떤 요청은 빠르게 받아주고, 어떤 요청은 소명받아야 하나?

## 2. 데이터

| 구분 | 내용 |
| --- | --- |
| 출처 | 한국은행 경제통계시스템(ECOS) Open API |
| 범위 | 2015년 1월 ~ 2026년 9월, 월별 141개월, 48개 시계열, 6,697개 값 |
| 구성 | 생산자물가지수 품목별 43개(원료·중간재·건자재·서비스), 생산자물가 총지수·화학제품, 수입물가 원유(원화기준), 두바이유(달러/배럴), 원/달러 환율(월평균) |
| 수집 | 2026-10-27, ECOS Open API `StatisticSearch`(sample 키, 10행 단위 페이지 조회). `src/fetch_ecos.py`로 같은 데이터를 다시 받을 수 있음 |

품목 코드와 분류는 `src/config.py`에 있습니다.

## 3. 전처리

- 두 원자료 파일을 월 기준으로 병합하고 결측·시작 시점을 점검(`outputs/tables/data_quality.csv`). 솔벤트만 2020년 12월부터 존재
- 2026년 2월(개전 직전 달)=100으로 재기준화(`data/processed/indices_rebased_202602.csv`)
- 월간 로그 변화율 계산(`data/processed/monthly_log_change.csv`)
- 화학공학적 공정 경로에 따라 원료 → 중간재 → 건자재 짝 21개를 정의

## 4. 분석 방법

| 분석 | 방법 | 결과 파일 |
| --- | --- | --- |
| 2026 충격 프로파일 | 2026년 2월 대비 3~9월 고점 상승률, 고점 시점, 고점 이후 되돌림률 | `shock_profile_2026.csv` |
| 비대칭 전이율 | Δln(제품) = Σ 상승분×β⁺ + Σ 하락분×β⁻ (시차 0~6개월), Newey-West 표준오차, 2015.2~2026.9 | `passthrough_asymmetry.csv` |
| 강건성 | 시차 3·9개월, 2025년 말까지 표본으로 재추정 | 같은 파일의 `*_lag3`, `*_lag9`, `*_pre2026` |
| 원료로 설명되는 상승률 | 2026 원료 상승률 × 추정 상승 전이율(90% 신뢰구간) vs 실제 | `explained_vs_actual_2026.csv` |
| 시장 요청 vs 지표 | 보도된 인상 공문·안내 vs 품목 지표 | `claims_vs_index.csv` |
| 기준시점 민감도 | 기준월(2025.6·9·12, 2026.2)별 상승률 차이 | `base_month_sensitivity.csv` |
| 2차 유가 상승기 | 2026년 7~9월 원료·자재 변화 | `second_wave_jul_sep.csv` |

## 5. 주요 결과

1. 같은 유가 충격이 자재마다 다르게 전이됐다. 2026년 2월 대비 고점 상승률은 원유(원화) 88.5%, 나프타 75.2%였다. 건자재는 우레탄 단열재 66.5%, 아스콘 41.8%, 플라스틱파이프 30.3%, EPS 단열재 17.4%, 유성페인트 12.8%, 암면(무기 단열재) 0%로 갈렸다.
2. 원유(원화)·나프타·PVC수지는 고점 뒤 70~81%를 되돌렸지만(원유 81%, 나프타 70%, PVC수지 76%), 10% 이상 오른 건자재 12개 품목은 0~34%만 되돌렸다(유성페인트·우레탄 단열재 0%, 아스콘 4%, 플라스틱파이프 7%, EPS 단열재 34%). 상승폭이 작았던 창호류(59%)와 판유리(100%)는 예외다.
3. 11년 데이터에서도 건자재 단계의 상승 전이율은 하락 전이율의 약 2배였다(유성페인트 0.16 대 0.08, 플라스틱파이프 1.29 대 0.53, 우레탄 단열재 0.89 대 0.41, 모두 p<0.01). 반면 원유 → 나프타 같은 원자재 단계는 대칭에 가까웠다. 비대칭은 시차·표본을 바꿔도 11개 경로에서 유지됐다.
4. 원료로 설명되는 폭과 실제를 비교하면 판단이 갈린다. 아스콘(설명 범위 18~62%, 실제 41.8%)과 도료는 원료로 설명된다. EPS 단열재(설명 범위 1~12%, 실제 17.4%)는 원료보다 더 올랐다. 우레탄 단열재는 MDI만 보면 과도하지만 폴리올까지 보면 설명된다.
5. 도료 업계는 3월 10~40% 인상 공문을 낸 뒤 2주 만에 평균 10% 안팎으로 낮췄고, 지표는 9~14% 올랐다. 시장이 결국 지표 수준으로 수렴했다.
6. 기준월만 바꿔도 결과가 크게 달라진다. EPS 단열재는 기준월이 2025년 6월이면 37.7%, 2026년 2월이면 17.4%로 20%p 차이가 난다.
7. 7~9월 두바이유는 45% 다시 올랐지만 건자재 지표는 −2.4%~+1.0%에 그쳤다. 2차 유가 상승을 이유로 한 재요청은 지표로는 아직 근거가 약하다.

## 6. 검증 도구 `src/verify_tool.py`

요청 한 건을 '자격 → 사실 → 범위 → 산정 → 결정' 5단계로 검증해 판정, 인정액, 근거, 법정 일정(10일·30일), 브리지 차트를 만듭니다.

| 판정 | 조건(기본값) | 조치 |
| --- | --- | --- |
| 신속 반영 | 요청 ≤ 지표 + 3%p | 요청액 인정, 합의서에 기준월·지표·산식·하락 시 감액 명시 |
| 소명 요청 | 요청 ≤ 지표 × 1.5 | 지표만큼 우선 인정, 증빙 제출 시 추가 인정 |
| 정밀 검증 | 그 외 | 지표만큼 우선 인정, 원가 구조 소명·복수 견적·직접 구매 단가 대조 |
| 기각·하락 반영 검토 | 지표 ≤ 0 | 성실 협의 후 서면 회신, 하락분 감액 협의 |

가상 요청 5건(`data/requests_sample.csv`)에 적용한 결과, 요청 합계 7억 500만 원 중 3억 4,754만 원을 우선 인정했습니다.
허용오차(2·3·5%p)와 소명배수(1.3·1.5·2.0)를 바꾼 9개 조합에서 4건은 판정이 같았고, 도료 1건만 경계 사례였습니다.

## 8. 한계

- 생산자물가지수는 국내 출하가의 전국 평균이다. 개별 계약의 규격·물량·지역 단가와는 다를 수 있어, 실거래 증빙으로 보완해야 한다.
- 2026년 7~9월 값은 잠정치로 개정될 수 있다.
- 전이율은 단일 원료 모형이다. 에너지·운송비·인건비 등 다른 원가는 따로 보지 않았다.
- 검증 도구의 정책 변수(허용오차, 소명배수)는 예시값이다. 롯데건설의 과거 조정 이력으로 보정해야 한다.
- 요청 사례는 모두 가상이다.
